# E-SPPD — Monitoring & Evaluasi Perjalanan Dinas

Salinan kode halaman publik dari https://esppd-monitor-wisnu.utomowisnu14.chatgpt.site/ yang diambil pada 21 Oktober 2026, dengan rekaman DASHBOARD ESPPD.mp4 sebagai acuan visual.

## Menjalankan

Buka `index.html` di browser, atau jalankan `npm start` dengan Node.js, lalu buka http://localhost:8080.

Tidak memerlukan instalasi dependensi atau proses build. Untuk GitHub Pages, pilih **Settings → Pages → Deploy from a branch → main → / (root)** setelah file diunggah.

## Fitur

- Ringkasan Eksekutif, grafik dan ringkasan anggaran.
- Monitoring Perjalanan beserta filter, pencarian, tabel dan detail transaksi.
- SLA Managed Service, status layanan agen dan informasi waktu proses.
- Ekspor CSV, cetak, dan penyimpanan perubahan di browser.

## Data dan batasan

Data, identitas, pagu, biaya dan waktu SLA pada aplikasi adalah simulasi sebagaimana ditandai pada halaman asli. Ini bukan integrasi dengan sistem produksi E-SPPD. Penyimpanan browser tidak ikut tersalin dari situs asli dan tidak dibagikan antar pengguna atau perangkat. Menggunakan domain baru menghasilkan penyimpanan browser yang terpisah.

HTML, CSS, JavaScript dan data bawaan dipertahankan dari respons publik. Satu skrip tantangan Cloudflare yang disisipkan oleh layanan hosting dikeluarkan karena bukan bagian aplikasi. Tidak ada aset eksternal atau panggilan API pada halaman yang disalin. Versi situs saat diambil dapat berbeda dengan versi yang direkam dalam video.

Hak atas kode dan identitas visual mengikuti pemilik aslinya; paket ini tidak menetapkan lisensi baru.
